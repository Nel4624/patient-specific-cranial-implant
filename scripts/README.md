# Engineering scripts

Planned **non-patient-specific** scripts:
- `mesh_metrics.py`: triangle count, bounds, manifold checks and statistics.
- `mesh_deviation.py`: quantify geometric error between reference and reduced mesh.
- `analysis_summary.py`: compare exported FEA result tables.

No patient models or derivatives should be committed. Document software versions, coordinate systems, units and tests for every script before relying on results.
