# 06 | Geometry and CAD workflow

## Stage 1: Original geometry (Mac, Blender)
1. Keep supplied anatomical STL unchanged; use a duplicate for all operations.
2. Confirm units and scale: STL does not encode units reliably.
3. Document orientation, topology, open edges, non-manifold elements and defect boundary.
4. Measure bounding box and relevant anatomy; capture private screenshots.
5. Test decimation at multiple ratios using copies only.
6. Quantify approximation error in **millimetres**, especially at the defect edge and fixation regions. A 90% triangle reduction is not automatically 90% loss of accuracy.

## Stage 2: Reconstruction
1. Establish approximate anatomical symmetry plane; quantify limitations of mirroring.
2. Evaluate mirrored contralateral surface versus smooth interpolation.
3. Reconstruct a smooth fitted implant reference surface.
4. Rebuild key geometry in CAD using controlled surfaces (including NURBS when justified), rather than blindly converting every skull triangle to a BREP face.
5. Preserve defect boundary/contact fidelity; verify internal clearance and overlap.

## Stage 3: SolidWorks
1. Confirm SolidWorks version, available reverse engineering features and Simulation licence.
2. Test a **small patch first** for surface/solid import and FEA suitability.
3. Consider a local cranial bone segment rather than the entire skull for tractable assembly contact FEA; document boundary condition sensitivity.
4. Add thickness, lip/tabs, holes, rounded transitions and candidate shell patterns as editable features where possible.
5. Use STEP/Parasolid where generated by a suitable CAD intermediary. Blender does not natively convert a polygon mesh to an editable NURBS STEP model.

## Geometry validation
- Max and RMS surface distance to original anatomy (mm).
- Defect boundary/fit deviation (mm).
- Watertightness, self-intersections and normals.
- Triangle/face count, file size, successful SolidWorks import and FEA suitability.

## Crucial distinction
The input STL triangle mesh is different from the discretisation of a CAD model for finite element analysis; both require separate quality controls.
