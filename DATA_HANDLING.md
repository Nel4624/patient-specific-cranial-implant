# Confidentiality and data handling

The cranial STL and challenge documents were supplied for an internship assessment. Their permissions and de-identification status have **not been independently verified**.

- Do not commit original anatomy, modified patient-specific anatomy, reconstructive implant geometry, CAD, screenshots showing identifying information, or supplied challenge documents to GitHub without explicit permission.
- Keep the repository private; privacy alone does not constitute authorization to upload.
- Keep anatomical files and native CAD/FEA results in an approved local or encrypted transfer location.
- Git ignores common CAD/medical formats, but **.gitignore is not a security boundary**. Check `git status` and staged files before every commit.
- Do not include patient names, birth dates, clinical identifiers or embedded DICOM metadata in documents or commit messages.
- Do not publish the repository or portfolio work until disclosure/IP permission has been obtained.
- Derived outputs remain subject to the same access restrictions as the original anatomical data.
